# Orvy 1.1.4

Reconoce el **firmware 4.18** y lo instala sola, como las versiones anteriores.

## Novedades

- **Los mandos giran al revés por defecto** con el firmware 4.18: el sentido
  que antes había que marcar en Ajustes → Sentido de mandos y rueda es ahora el
  normal. Si tenías marcados los mandos, al actualizar volverán a girar como
  antes: desmárcalos para quedarte con el sentido nuevo. La rueda no cambia.

## Compatibilidad

Reconoce hasta el firmware 4.18. Con uno anterior funciona igual que la 1.1.3.
