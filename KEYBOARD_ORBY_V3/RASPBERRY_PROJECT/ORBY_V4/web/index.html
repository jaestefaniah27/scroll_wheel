OrbyGUI para Windows

La aplicación con la que se configura el teclado: perfiles, páginas, iconos de las pantallas, secuencias y complementos. Solo hace falta para editar; el teclado funciona sin ella.

Última versión

Windows te va a avisar, y es normal

El instalador todavía no va firmado. Un certificado de firma cuesta entre 250 y 700 € al año, y de momento este proyecto no los tiene; en cuanto los tenga, el aviso desaparece. Mientras tanto, Windows enseña la pantalla azul de SmartScreen.

  1. En el aviso, pulsa Más información.
  2. Pulsa Ejecutar de todas formas.
  3. Comprueba antes que el fichero es el nuestro, con la huella SHA-256 que se publica junto a cada versión.
Get-FileHash .\OrbyGUI-Setup.exe -Algorithm SHA256
