# Firmware 4.13

## SUPER + menú

Con **SUPER** mantenida, la tecla de menú funciona como atajo:

- **Pulsación corta:** retrocede de página.
- **Pulsación larga:** abre el menú principal, que se queda abierto al soltar.

## Pantallas del Inicio sin recortes

Mientras se mantiene la tecla de menú para elegir perfil, el bucle que espera
la elección sigue enviando las pantallas al PC: la app ve el cambio en tiempo
real.
